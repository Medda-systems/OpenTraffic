# Orbit — collaboration test site

A fake four-page product site for trying OpenTraffic's live collaboration.

```sh
Examples/collab-demo/serve.sh        # http://localhost:4747
```

| Page | What to try |
| --- | --- |
| Home | Cursors land on the same button or card for everyone; scroll while leading. |
| Features | Long page: Lead, switch pages, and watch followers jump and scroll with you. |
| Pricing | Point at a plan; cursors stay on the card at any window size. |
| Docs | A mini single-page app (pushState) — following still works; the contact form shows that typed text is never shared. |
